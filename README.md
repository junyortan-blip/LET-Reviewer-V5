# LET Reviewer V5 — Android Studio Project

This project packages the 1,005-question LET Reviewer V5 HTML app into a native Android WebView application.

## Included
- 1,005 original LET-focused practice questions
- 600 English Major
- 200 Professional Education
- 205 General Education
- English Major coverage includes grammar, linguistics, literature, language assessment, research, speech, reading and writing, and English teaching.
- Random 50 practice
- 100-question mock exam
- Explanations
- Mistake review
- Score/accuracy tracking
- Offline operation
- LocalStorage progress
- Android launcher icon

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync/download dependencies.
3. Select Build > Build App Bundle(s) / APK(s) > Build APK(s).
4. The debug APK will be generated under:
   app/build/outputs/apk/debug/

The questions are original practice material, not official or verbatim PRC exam questions. Topic coverage was guided by the PRC's published [2025 Table of Specifications for English (Secondary)](https://www.prc.gov.ph/sites/default/files/2025-11%20published%20PROFESSIONAL%20TEACHERS.pdf).
