# LET Reviewer V5 — Android Studio Project

This project packages the 1,005-question LET Reviewer V5 HTML app into a native Android WebView application.

## Included
- 1,005 original practice questions
- 600 English Major
- 200 Professional Education
- 205 General Education
- Random 50 practice
- 100-question mock exam
- Explanations
- Mistake review
- Score/accuracy tracking
- Offline operation
- LocalStorage progress
- Android launcher icon

## Build
1. Open this folder in Android Studio.
2. Let Gradle sync/download dependencies.
3. Select Build > Build App Bundle(s) / APK(s) > Build APK(s).
4. The debug APK will be generated under:
   app/build/outputs/apk/debug/

The generated questions are original practice material and are not official PRC exam questions.
